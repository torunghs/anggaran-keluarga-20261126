DompetKeluarga — situs anggaran rumah tangga untuk keluarga Indonesia, dibangun sebagai berkas statis biasa tanpa permintaan jaringan. Enam halaman tertaut (Beranda, Anggaran, Transaksi, Laporan, Kalkulator, Tips &amp; Sumber) dengan angka contoh realistis dalam rupiah: gaji, belanja pasar, token listrik, SPP sekolah, dan seterusnya — tiap angka acuan dijelaskan sumbernya. Tambah, ubah, dan hapus transaksi (tersimpan di localStorage), pilih bulan, cari, saring, dan urutkan transaksi, atur anggaran per kategori dengan slider dan progress bar, kalkulator aturan 50-30-20 dan dana darurat, serta grafik SVG murni (donat kategori, batang bulanan, garis tren) — semua berfungsi di desktop dan ponsel.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
